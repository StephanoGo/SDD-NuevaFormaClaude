# Registro de revisión histórica de reglas

Esta checklist ya no es normativa. Sus reglas vigentes están resumidas en las specs activas de [Citas](../../modulos/citas.md) y [Atenciones](../../modulos/atenciones.md). El análisis completo permanece en el historial de Git.

Observaciones antiguas que no deben tratarse como requisitos aprobados: conflicto de reservas de un mismo paciente, impedir atender antes del horario reservado, política de cancelación y autenticación del médico. Resolver cada una en una spec si el producto la necesita.

La implementación y la spec funcional de Core permiten receta opcional; una checklist anterior lo contradijo. Mantener receta opcional hasta que el responsable de producto decida y se actualice la spec.
