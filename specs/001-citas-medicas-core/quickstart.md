# Inicio rápido

Requisito: SDK de .NET 10.

```sh
dotnet build
dotnet test
dotnet run --project src/CitasMedicas.Api
```

La API sirve la SPA desde `wwwroot`. Rutas HTTP vigentes: [`contracts/api-contracts.md`](./contracts/api-contracts.md). Para validar un cambio, seguir los criterios de la spec activa del módulo correspondiente.
