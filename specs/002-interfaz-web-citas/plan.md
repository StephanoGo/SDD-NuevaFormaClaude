# Cierre histórico: Interfaz web original

La interfaz se sirve como archivos estáticos desde la API y usa HTML, CSS y JavaScript estándar. Agenda, pacientes, reservas y atención comparten la aplicación web; las reglas de negocio se validan también en el servidor.

Las specs de módulo contienen los criterios vigentes. El plan detallado de la entrega inicial permanece en el historial de Git y no dirige cambios nuevos.
